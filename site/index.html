We’ve watched agents scroll by before. This time we built them an office.

$ git clone https://github.com/MitchellKevin/the-agentic-office.git

then cd the-agentic-office && npm start · open localhost:4317 · Node 20+

The robots

Every Claude Code session is a robot at a desk.

Its face tells you what it’s doing. Pick a state, or use the robot button in the dock to cycle through them.

The office

One building. A floor for every project.

Pick a floor and the camera flies in. Desks are grouped per git branch, and new agents get their own worktree. Click any robot to read along, or type its next task.

The privacy

It never leaves your machine.

  • Binds to 127.0.0.1 only. No accounts, no telemetry, no outbound requests.
  • Transcripts are opened read-only.
  • Host, Origin and a per-run token guard every approval.
  • Loads nothing from a CDN, enforced by a strict CSP.
